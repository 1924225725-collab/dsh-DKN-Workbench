# 插画工作台运行素材

由内置 image_gen 基于用户确认的角色设定稿与首页概念图生成；原始PNG包含真实Alpha透明通道。不是Rive文件或连续逐帧动画。

- dispatch-desk.png：暖木色调度台、路由符号显示器、台灯与纸箱；无背景和文字。
- courier-deliver.png：浅金发圆框眼镜，蓝白条纹与米白背心，抱纸箱向右迈步的精细2D绘图角色；无背景和文字。

提示词要点：精细手绘墨线与柔和赛璐璐明暗、低饱和暖木/米白/鼠尾草色，保持已确认人物一致性，完整独立物体、透明安全边距，不包含参考截图中的手机UI和水印。

scripts/build.mjs 将这两个素材编码到 lib/client.js，安装包/独立后台不依赖工作目录文件或远程图片。首页使用位移/浮动衔接，不应宣称已制作全套角色姿态动画或Rive绑定。
