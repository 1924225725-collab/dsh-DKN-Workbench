# CodeBuddy 通道

DKN Agent 保留原 CodeBuddy CLI 插件中的国内版与国际版模型通道。它们通过各自官方 CLI 向 DSH 提供模型输出；不会调用 Codex，也不会把请求转发给 Codex。
