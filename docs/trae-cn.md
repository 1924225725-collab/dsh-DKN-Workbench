# TRAE CN 国内个人版

模型与平台 → TRAE CN。支持国内个人版桌面账号，不依赖仅供企业旗舰版使用的官方 CLI。

1. 在官方 TRAE CN 客户端完成登录。
2. 点击“检测登录与模型”。安装位置按 Windows 用户安装信息自动发现，可手动指定安装目录/EXE；数据目录默认使用当前用户的 Trae CN。
3. 点击“发送测试”，收到真实回复后才显示可用。DSH 普通对话可选择 TRAE CN 下账号实际可用的模型；未解锁和用户自定义外部 API 模型不进入目录。
4. 在额度与用量页查看积分，在模型与平台页查看签到状态和手动一键签到。
5. 自动签到需同时开启全局开关与 TRAE 配置页的“TRAE 加入自动签到”（默认关闭），沿用北京时间11:00–13:00随机计划、每日去重及结果不确定不重试规则。
6. API 服务先验证具体 TRAE 模型，再选择保存路由。对外仍填写统一模型名 dkn；验证只在当前后台有效30分钟。API 与自动签到使用现有独立后台，可按原开关在退出DSH后继续运行。

## 范围与状态

支持文本和文本历史、动态目录、账号声明的推理档位、实际剩余积分（总额度减消耗）、每日签到、统一配置页/可用状态/真实验证、两种界面风格与 API 后台。当前不支持图片/文件附件、DSH工具桥接或独立账号池；不能宣称与支持图片的 CodeBuddy 国内版完全等价。

TRAE 个人版使用桌面远程会话接口，不是企业 CLI ACP。当前接口依赖桌面版本，升级可能需要适配。登录态仅本机内存使用；不复制令牌到插件配置/后台配置或日志，过期后请在官方客户端重新登录。只向已核对的国内上游与 api.trae.cn 发送凭据；不跳过账号权益、设备验证或验证码。每日领取使用官方登录态原有设备标识，缺少时提示使用官方客户端。
