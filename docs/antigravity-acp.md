# Antigravity CLI（ACP）

在「模型配置 → Antigravity」管理。提供模型选择、官方登录命令、CLI 路径、代理、工作目录和真实回复测试，使用与其他平台相同的配置页布局。

## CLI 与代理

使用官方 `agy` CLI（本次实测版本1.5.9）。留空路径时自动检查用户数据目录的 `dsh-dkn-agent/antigravity-cli/agy.exe`、`%LOCALAPPDATA%/agy/bin/agy.exe`、用户 `.local/bin` 和 PATH。其他位置可填写完整路径。插件安装包不包含221 MiB的官方EXE，其他电脑需从官方安装或自行填写路径；当前验证电脑已把校验通过的EXE放进用户私有目录。

登录使用配置页给出的 `agy acp --login` 命令。默认仅继承当前运行环境并读取已启用的 Windows 手动系统代理；也可填写 HTTP/HTTPS/SOCKS5 代理地址，它只用于子进程，不修改系统或其他平台。PAC不在自动解析范围内。认证代理应在运行环境配置，页面地址不接受用户名密码。

## 可用性

握手和模型目录可读只标记“待验证”。仅真实文字正常结束后才标为可用。官方 `Verification Required` 提示及账号/地区资格限制按错误处理，不显示为成功回复，也不自动更换账号、代理节点或伪装客户端。

当前实现支持文本，每次请求创建独立ACP会话并附带文本历史；客户端文件、终端能力不开放，新增权限请求一律拒绝。官方CLI仍有自己的原生工具。为避免服务验证提示误作正常文本，初版先等待回合完成并校验，再整段返回；不会伪造逐字流式或Token用量。插件保守使用128K上下文预算，实际容量仍受官方模型限制。

## 独立后台与 API

后台直接使用同一适配器，可在 DSH 退出后继续调用。配置或系统代理调整后可重新检测和测试。API页可将统一公共模型名（默认 `dkn`）路由到 `antigravity-acp/<官方模型ID>`；需要在当前后台完成真实回复验证，30分钟有效。目录可读、配置页握手、验证码提示都不会自动授予API导出资格。

本机2026-11-16实测仍返回官方验证/地区资格提示，没有收到模型回复。本版先加入通道，供用户完成官方验证、调整合法网络配置后自行复测；不能把已添加通道宣传为已验证可用。暂无官方余额/签到接入，额度请在官方客户端查看。
