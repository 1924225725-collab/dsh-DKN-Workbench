# 独立后台

API 服务与自动签到从 2.2.4 起共用一个独立 Node.js 后台。插件是启动与配置入口；后台直接调用本机官方 CLI 或已接入的官方每日奖励接口，不依赖正在运行的 DSH 模型服务。

## 使用

1. 在「模型配置」或「API 服务」找到「后台服务」，点击启动。配置查询也会按需启动后台。
2. 开启「退出 DSH 后继续运行」，后台便不会随 DSH 正常退出而停止。默认关闭；未开启时，插件卸载生命周期会请求后台停止。
3. 如需重启电脑后继续使用，再开启「随 Windows 登录启动」。它使用当前用户的 Windows Run 项及隐藏启动脚本，不需要管理员权限。不开启就不会修改此自启项。
4. API 原地址、Key、公共模型名和目标选择保留。若希望 Windows 登录启动后台后也自动开启 API，需在 API 页保存「随后台自动启动 API」。仅开启后台自启不会自动开启原本关闭的 API。
5. 签到只在「模型配置」展示。开启「自动签到」后沿用每天北京时间 11:00–13:00 随机一次、先查再领、失败不自动重试的规则。仅覆盖 CodeBuddy 国内当前选中账号及已启用 Qoder 的国际桌面账号。保留原计划和当天执行记录，不因重新打开 DSH 重领。电脑关机/休眠错过窗口后等次日，不在窗口外补签。

停止后台会停止 API 与签到。后台停止后，当前插件窗口的状态轮询不会重新启动它；显式点击启动、执行配置操作，或重启 DSH 后按保存的设置可再启动。关闭开关不能撤回已经发给官方的请求。

## 数据、升级与移除

默认数据目录：`%LOCALAPPDATA%\dsh-dkn-agent`。API 设置、Key 哈希和签到计划沿用原文件；后台配置仅保存 CLI 路径和运行参数，不复制官方登录凭据。控制连接走经过独立随机密钥认证的本机命名管道，控制密钥与对外 API Key 分开，不输出到页面。

后台运行文件与所需 Node.js 复制到该数据目录的 `background-runtime` 下，避免依赖被替换的插件目录。后台会检测并复用独立 Node.js 24.9+；Electron 宿主本身不再阻止安装后台。缺少环境时，页面提供可复制给自己 AI 的部署提示词，详见[运行环境](background-environment.md)。平台 CLI 与登录仍需预先安装/完成，后台不会修复过期登录或不足额度。

打开较新插件会检查后台版本，先停止旧后台，再使用新版本运行文件启动。升级会中断后台的在途请求，请避开正在生成回复时升级。不同版本共用同一控制地址，重复打开插件会复用同一后台。

卸载插件前，请在页面关闭「随 Windows 登录启动」和「退出 DSH 后继续运行」，再点击「停止后台」。插件被直接删除时无法保证执行清理，因此常驻文件不会自动销毁；需要手动清理时也应先停用自启并停止后台。已有 API 配置和签到记录保留，避免卸载误删账号相关数据。

## 验证范围

自动测试使用隔离目录和合成 CLI 验证独立进程、启动宿主真正退出后 API 仍回复、重复启动复用、停止后轮询不重启、API Key与签到计划保留、控制认证与中文路径启动脚本。Windows 登录自启注册操作使用测试替身，未在用户电脑上实际安装自启项。

真实 CLI 验证在关闭插件管理连接后收到 CodeBuddy 国内、Codex CLI、Qoder ACP 的 `OK` 回复；每日奖励仅做官方状态查询，没有真实领取。ZCode 复用原有适配器，需当前后台内验证成功且受原套餐/认证限制，本次未新增真实 ZCode 回复验证。
