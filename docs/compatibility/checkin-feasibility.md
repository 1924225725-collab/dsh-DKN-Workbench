# 每日奖励接入与兼容范围

自 2.1.3 起支持手动领取；2.1.4 在配置页顶部增加状态汇总和一键签到；2.1.5 修复 Qoder 缺少官方桌面身份导致每日活动漏查。

| 平台 | 当前能力 | 账号来源 |
| --- | --- | --- |
| CodeBuddy 国内版 | 查询签到状态、手动领取每日奖励、号池逐账号入口 | 官方 CLI 默认登录或插件选中的独立账号环境 |
| Qoder 国际版 | 查询每日 100 Credits 活动状态、手动领取该活动 | Windows Qoder 国际版桌面当前登录；可能与 CLI 账号不同 |
| CodeBuddy 国际版、Qoder 国内版 | 尚未开放领取 | 不跨区域复用登录凭据 |
| ZCode | 额度查询；活动领取暂未接入 | 对应配置通道的官方登录 |
| DeepSeek、Codex | 余额／限额查询；没有签到按钮 | 对应官方账号或运行时 |

## 使用行为

- 进入配置页只查询状态，不自动领取。只有点击“一键签到”或账号的单独按钮时才执行领取。
- 总入口依次处理 CodeBuddy 国内当前默认账号、Qoder 国际桌面账号，不遍历整个号池。其他独立账号在各自入口操作。
- 领取前重新查询状态；已领取、没有活动或不符合资格时跳过。某个平台失败不阻塞其他平台。
- Qoder 每轮为北京时间当天 10:00 至次日 10:00。不能将“没有下发活动”当作“已领取”，也不能把新人／订阅礼包当成每日奖励。
- 请求中断、服务端错误或回执无法确认时不自动重试领取；先刷新状态，在官方客户端核对实际结果。
- 资格或验证受限时使用官方客户端处理；插件不生成替代设备身份、不自动处理验证码、不刷新令牌或修改原生登录文件。

Qoder 每日奖励使用指定桌面端的本机登录状态。Windows 当前用户解密只在本机内存中进行，认证仅用于固定 Qoder 官方接口；页面与日志不接收令牌。活动查询与手动领取复用本机官方桌面组件返回的真实身份，缺少身份时明确报错，不把不完整列表判定为无活动；不生成替代设备。桌面路径可自动发现或在配置页指定。CodeBuddy 查询和领取沿用同一个账号环境与区域检查。

## 验证范围

两个已接入平台的状态查询经过真实只读验证。领取、重复点击合并、错误处理、账号路由、周期切换与顶部汇总流程经过模拟上游接口和本地浏览器回归。没有把模拟领取当成真实账号领取成功；实际安装后的 DSH 宿主行为仍需验收。官方活动、资格与接口可能调整，状态以平台当前返回为准。
