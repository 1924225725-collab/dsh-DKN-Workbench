# 项目协作功能对照（2.1.1）

项目和对话直接使用 DSH 工作区数据；每条对话是一个成员。原版的独立项目创建、外部软件连接与独立成员运行时设置不在插件中重复提供。

| 功能 | 当前入口与行为 |
| --- | --- |
| 项目概览 | 概览：目标、进度、风险、里程碑、技术栈、目录、近期事件与交接摘要导出 |
| 集中处理 | 待办：待验收任务、阻塞流程、协助申请、原生授权、用户问题、待交接消息、不确定执行与回执 |
| 群聊和单聊 | 对话：选择单聊成员、精确 @、多接收成员、关联任务、消息复制、历史加载与当前聊天导出 |
| 提示词分析 | 对话：选择现有成员分析草稿，展示意图、问题和优化稿；人工采用，或预先明确选择分析后发送 |
| 成员 | 成员：职责预设、指令、权限、头像、打开原生会话、历史同步；模型在 DSH 原对话选择 |
| 任务 | 任务：父子任务、执行者和审查者筛选、状态筛选、依赖、自测、独立审查、重试和人工验收证据 |
| 执行记录 | 执行记录：状态、标识、关联、输出、错误、停止调度、中断原生执行与不确定结果核对 |
| 流程设计 | 工作流／流程模板：角色、节点、入口、成功／失败连线、人工审批、访问次数限制、JSON 编辑和导入导出 |
| 流程管理 | 模板复制、置顶、排序、删除；运行重命名、置顶、排序、导出和结束后删除；暂停、继续、停止、人工介入与角色绑定 |
| 顺序协作 | 工作流／顺序协作记录：成员顺序执行和历史记录 |
| 项目文件 | 文件与产物／项目文件：目录扫描、搜索、大小、Git 变更与从文件登记产物 |
| 任务产物 | 文件与产物／任务产物：关联任务和成员、版本、检查、文本／图片预览、原文件下载与关联消息 |
| 问题记录 | 问题记录：搜索、状态、阻塞信息及详情维护 |
| 审计与恢复 | 审计与恢复：搜索、加载更早记录、备份导出与合并恢复 |

权限仍由 DSH 原生对话及协作权限共同约束。提示词分析发送到所选现有成员，不创建独立软件连接。执行结束不等于验收通过；不确定提交需人工核对，不能直接重发。

本地浏览器回归使用模拟 DSH 和模型回复，覆盖上述主要操作。它不能代替安装后对 DSH 真实项目、授权和模型执行的验收。
