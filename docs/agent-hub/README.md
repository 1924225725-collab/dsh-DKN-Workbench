# DSH 项目协作

项目协作 直接使用 DSH 工作区：每个工作区项目对应一个协作项目，项目中的每个对话对应一个成员。协作功能 不再另建项目、另建成员或接入外部软件。

## 使用

1. 从左侧 项目协作、DKN Agent 首页或总设置进入。
2. 项目列表自动读取 DSH 工作区。需要新增项目或对话时，请在 DSH 工作区操作；改名、移动和移除也会同步。没有项目时显示明确引导，读取服务失败会报错。
3. 选择项目，进入「成员」编辑对话的职责、补充指令和协作权限。模型沿用原对话的当前选择，在原对话中切换。自动发现的对话默认不开启发送、任务执行和转交权限。
4. 在「对话」选择收件人或精确 @成员后发送。成员使用自己原有的 DSH 上下文；不指定收件人时只保存群聊记录。第一次联系成员时带上项目背景和职责。
5. 在「任务」指定执行者、独立审查者、验收标准和依赖；在「工作流」配置顺序实施、独立审查与人工收口。执行结束和验收通过分开记录。

协作功能 通过宿主 Session Controller 发送、同步历史和中断，模型与工具审批沿用 DSH。打开 协作功能、同步列表、配置职责均不会自动请求模型。协作功能 不直接启动或连接其他 Agent 软件。

## 同步与执行

项目和成员沿用稳定映射；改名不会重新建档，对话移动后只属于新的项目。移出的对话撤销协作权限并保留历史记录；发送前会再次检查 DSH 归属，避免向已移出的对话继续派发。旧版本的独立协作数据保留在本地，不自动创建 DSH 项目或对话。

不重叠目录最多并行四个，同目录和父子目录排队。排队只约束 协作功能 内发起的任务，手动对话和其他编辑器仍可能修改文件。需要并行写同一仓库时，请在 DSH 中使用独立工作树目录。

暂停流程、停止后续调度与请求原生中断分开处理。断线或回执丢失不自动重发；先同步原生历史并人工记录实际结果，再解除阻塞。重启后流程不自动恢复执行。

## 文件、审计与备份

「文件与产物」只读预览项目文件、登记产物并检查存在性；存在不等于验收通过。访问限制在项目目录内，拒绝符号链接越界及常见凭据文件。

「审计与恢复」导出或合并协作备份。备份包含协作消息、路径、职责、权限与证据。导入前保存独立备份，新导入成员默认关闭权限，项目与对话归属仍以 DSH 为准。

## 来源与验证

复用 Agent Hub 2.3.1 的任务、工作流、审查、消息路由和审计领域核心，以 DSH 原生项目及会话适配替代独立软件接入。MIT 许可见 [LICENSE](LICENSE)。

自动化测试覆盖原生工作区／对话映射、重命名与移动、归属撤销、读取失败、DSH 会话发送，以及浏览器内任务和工作流。模型响应使用合成数据；不代表真实模型的完整多成员任务已验收。


## 配置与整理

项目说明可填写目标、当前进度、风险、里程碑和技术栈；项目名称及目录仍由 DSH 管理。

任务支持父子关系、前置依赖、开发自测和独立验收。对话中的消息可关联任务，产物可关联消息并登记版本与提交成员；这些关联只记录来源，不改变验收结果。「问题记录」按项目维护问题、阻塞标记和处理状态。

协作流程支持编辑、复制、置顶、导入／导出 JSON 和删除模板；删除前确认并保存本地备份，已有运行记录保留自己的模板副本。也可选择已有、允许发送的项目对话来生成流程设计；生成结果需手动保存成模板，不会自动执行。

控件跟随 DSH 的浅色／暗色主题。保存或同步期间仍可切换页签；请求失败显示错误并恢复按钮，请先核对不确定的提交回执再重试。

收件人可以直接勾选；若尚未允许协作发送，会出现「开启所选对话发送权限」。确认后只开启手动发送，不启用任务自动执行或成员转交。单聊按钮高亮并显示当前对话范围。
